# I2C 
## Introduction
I2C is a two wire protocol.
1. SCL (Serial Clock) : Master decide clock & speed.
2. SDA (Serial Data)  : Data signal, dual transfer.

## Protocol communication
1. Start : SCL 1 / , It indicate 
2. Address transfer
3. ACK/NACK
4. Data
5. Stop
